# TalentBridge - Decentralized Freelance Marketplace

A blockchain-powered freelance marketplace built on Stacks, connecting clients with talented freelancers through transparent escrow and mediation.

## Features
- Project posting and management
- Freelancer bidding system
- Escrow payment protection
- Dispute resolution mechanism

## Smart Contract Functions
- `post-project`: Create new project listings
- `submit-bid`: Freelancer bid submission
- `complete-project`: Mediator project completion
- `get-project`: Retrieve project details
